# Phonon calculation records

[← Repository guide](../README.md#analysis-workflow) · [Finite-temperature analysis](../finite_temperature_hull_analysis.ipynb#phonon-acceptance-gates)

This directory retains the unmodified calculation records for the 25 cells shown in Supplementary Figure 25: six quaternary targets and 19 selected tie-plane endmembers. The analysis, results and reproduction instructions are collected in the main README and the finite-temperature notebook.

| Path | Record |
|---|---|
| `cells.txt` | The 25 composition labels. |
| `cells/<composition>/POSCAR-unitcell` | Relaxed 12-atom unit cell. |
| `cells/<composition>/phonopy_disp.yaml` | Supercell matrix and displacement dataset. |
| `cells/<composition>/FORCE_SETS` | Forces collected from the displacement calculations. |
| `cells/<composition>/thermal_properties.yaml` | Vibrational thermal properties on the 0–1200 K, 10 K grid. |
| `cells/<composition>/mesh.yaml` | Frequencies on the 31×31×1 q-mesh. |
| `cells/<composition>/vasp/run-NNN/vasprun.xml.gz` | Compressed VASP force-calculation output; `run-000` is the undisplaced reference. |
| [`vasp/INCAR`](vasp/INCAR), [`vasp/KPOINTS`](vasp/KPOINTS) | Shared VASP settings. |

Energetic inputs and reference tables are stored in [`data/`](../data/), and figures in [`figures/phonons/`](../figures/phonons/). The notebook reads the included phonopy outputs. Repeating the upstream calculations requires VASP and phonopy.

## Calculation provenance

The supplied upstream calculation workflow starts from one entry of the 2x2x1 CCS — the symmetry-unique configuration
set the convex-hull analysis is built on — and reaches `cells/<composition>/` through the
following stages. This folder includes the relaxed unit cells and phonopy/VASP outputs;
the scan, fit, and prerelaxation intermediates are not included.

1. **CCS template.** The entry is pulled from `ccs_all_train.xyz` by its `ordinal_id` and
   written as an unrelaxed 12-atom `POSCAR-template` (`ccs_templates/`).
2. **Fixed-c in-plane scan.** The vacuum axis is *not* relaxed: `c` is held at **21.4 A**
   and only the in-plane lattice is scanned, so that a monolayer cannot collapse its own
   vacuum gap or drift between cells.
3. **Fit.** The scan is fitted to locate the in-plane minimum.
4. **Prerelax** of the fitted cell in a 6x6x1 setting.
5. **Symmetry projection ("space-group recovery").** The relaxed cell is snapped onto the
   space group detected at a 1e-3 tolerance. This is the step the differences below come
   from.
6. **Prerelax_v2** of the projected cell.
7. **Displacements** generated by phonopy in a 3x3x1 supercell (108 atoms).
8. **Forces** from VASP, one run per displacement (`vasp/run-NNN/`).
9. **Collect** into `FORCE_SETS`, then `thermal_properties.yaml` and `mesh.yaml` via
   `phonopy-load --tolerance 1e-5 --pa="1 0 0 0 1 0 0 0 1" --mesh 31 31 1 -t
   --tmin 0 --tmax 1200 --tstep 10`.
10. **Gates** — acoustic-frequency tolerance, mesh-frequency threshold, natom == 12 — enforced again in
    the notebook via `analysis/phonons.py` before a cell may enter the F_vib table.

## Vacuum axis and q-mesh

**The q-mesh is 31x31x1 for all 25 cells.** What differs between cells is only the number
of *irreducible* q-points phonopy then needs, and that is fixed by the space group found at
step 5:

| irreducible q-points | space groups (tolerance 1e-3) | cells |
|---|---|---|
| 96 | P-6m2 (187), P3m1 (156) — trigonal/hexagonal | 9 |
| 256 | Aem2 (39), Pmn2_1 (31), Pmm2 (25), Cm (8), C2 (5) | 16 |

The same step is the origin of the spread in the vacuum axis. The scan sets `c` = 21.4 A for
every cell, so any cell that comes out of step 5 unchanged still carries exactly that value:

| | n | c (A) | vacuum gap |
|---|---|---|---|
| space group recovered (`.symlog` written) | 19 | 20.0440 – 21.7962, mean 20.968 | >= 16.69 A |
| no change logged | 6 | **21.4000 exactly** | >= 17.94 A |

The six that kept the scan value are `Mo4Se6S2`, `W2Mo2Se1S7`, `W3Mo1Se1S7`, `W3Mo1Se6S2`,
`W4Se5S3`, `W4Se6S2`.

So the 1.75 A spread in `c` across the set is **not** a difference in vacuum convention and
not a relaxation of the vacuum axis — it is the geometry change introduced when a cell is
projected onto its recovered space group and re-relaxed. Across all 25 cells the in-plane
lattice stays within 6.3739-6.6470 A, the slab is 3.127-3.480 A thick, and the vacuum gap
never falls below **16.69 A**. These values describe the supplied geometries; a separate
vacuum-separation convergence sweep is not included in this record.

## Method

Finite displacements with **phonopy 4.4.0**; forces from **VASP 6.4.3** (PBE, ENCUT 500 eV,
EDIFF 1e-8, ISYM = 0, ADDGRID, LREAL = .FALSE.; PAW_PBE potentials `W_sv` 04Sep2015,
`Mo_sv` 02Feb2006, `Se` 06Sep2000, `S` 06Sep2000) on **3x3x1 supercells of the 12-atom cell
(108 atoms)**; thermal properties on a **31x31x1** q-mesh.  `ISYM = 0` is deliberate: the
displacements break the symmetry and phonopy must be the sole authority on it — the same
reason the symmetry projection at step 5 above is done once, before the displacements, and
never re-applied afterwards.  Per-cell irreducible q-point counts and the vacuum-axis
spread are set by that step and are tabulated above.

Every cell passes three gates before entering the F_vib table, enforced by `analysis/phonons.py`:

* \|max acoustic frequency at Γ\| < 0.05 THz (acoustic sum rule),
* no mode below −0.05 THz anywhere on the mesh,
* natom == 12.
