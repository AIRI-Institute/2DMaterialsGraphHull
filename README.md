# MX2CHE

**MX2CHE** is a research project that applies Graph Neural Networks (GNNs) to predict formation energies and convex-hull stability of two-dimensional transition metal dichalcogenides (TMDs) containing point defects (vacancies and substitutions). The study combines large-scale crystal structure databases with advanced machine learning architectures to accelerate the discovery of stable defect configurations in materials such as MoS₂ and WSe₂.

This repository accompanies the paper:

> **Chemical disorder and defects in MeX₂ (Me = Mo, W; X = S, Se) monolayers by means of data-driven approach**  
> Roman A. Eremin, Aliaksei V. Krautsou, Innokentiy S. Humonen, Alexander A. Ryabov, Kuzma A. Khrabrov, Artem D. Dembitskiy, Aleksandr S. Antropov, Albert R. Efimov, Kostya S. Novoselov, Semen A. Budennyy  
> (2026)

## Overview

The project investigates the energetics of defective TMD monolayers using two complementary data sources:

- **CCS (Composition/Configuration Space)** – a custom database of crystal structures generated by enumerating symmetrically inequivalent defect arrangements in supercells.
- **2DMD dataset** – an existing library of 2D materials point defects (https://2dmd.airi.net/), used for training and validation.

We train GNN models (Allegro and NequIP) on various subsets of these data, including low‑defect‑concentration (LDC) and high‑defect‑concentration (HDC) splits, and evaluate their performance on hold‑out test sets (HT#1, HT#2, and preliminary tests). The notebooks also perform convex‑hull analysis, configurational entropy calculations, and descriptor‑based interpretability.

## Key Results

- **Configuration Space Construction:**
A complete composition/configuration space (CCS) was built for a 2×2×1 WSe₂ supercell, covering 420 distinct compositions and 11159 symmetry‑unique configurations (after removing symmetry duplicates). This set spans a wide chemical and configurational diversity, including high vacancy concentrations (up to 50 % on each sublattice).

- **Thermodynamic Landscape at 0 K:**
Convex‑hull analysis reveals that only 1.7 % of the CCS configurations lie within 25 meV/atom above the hull. The vast majority of structures with high vacancy content are strongly unstable.

- **GNN Prediction Accuracy:**
Graph neural network models (Allegro and NequIP) achieve formation‑energy root‑mean‑square errors (RMSE) of 10–13 meV/atom on out‑of‑domain holdout tests, enabling reliable screening of millions of configurations at negligible computational cost.

- **Structured Training Data Outperforms Random Sampling:**
Models trained on systematically generated, symmetry‑aware datasets (the CCS or the low‑defect‑content 2DMD subset) generalize far better to unseen defect concentrations and supercell sizes than models trained on sparsely sampled random configurations. This highlights the importance of structured sampling for robust ML performance.

- **Highly Defective Quaternary Alloys Remain Unfavorable:**
Even after exhaustive configurational sampling and inclusion of configurational entropy, quaternary compositions with six defects (e.g., W₁Mo₁₄Se₂S₂₈ and W₁₄Mo₁Se₂₈S₂) remain ~95 meV/atom above the free‑energy hull at 1200 K. Entropy alone cannot stabilize such heavily defective phases.

- **Dominant Defect Type: Chalcogen Vacancies (V<sub>X</sub>):**
Chalcogen vacancies are identified as the thermodynamically most accessible intrinsic defects, with free energies above the hull of only 20–40 meV/atom at temperatures up to 1200 K. In contrast, metal vacancies (V<sub>Me</sub>) are consistently less favorable, lying 70–100 meV/atom above the hull.

- **Alloy Composition Tunes Defect Stability:**
Alloying on both the metal and chalcogen sublattices significantly modifies vacancy energetics. The lowest V<sub>X</sub> energies are found in Mo‑rich sulfur‑containing alloys (e.g., Mo₁₆Se₃₂−yS<sub>y</sub> with high S content), which offer a favourable playground for defect engineering.

- **Finite‑Temperature Entropic Stabilisation:**
Inclusion of configurational entropy qualitatively changes the stability landscape. Many ternary and quaternary low‑defect alloys, which appear metastable at 0 K, become thermodynamically accessible at relatively low temperatures (≈160–240 K). This demonstrates that free‑energy analysis is essential for realistic materials discovery.

- **Interpretable Machine Learning Reveals Stabilising Motifs:**
Descriptor‑based analysis shows that nearest‑neighbour V<sub>Me</sub>–V<sub>X</sub> pairs provide the strongest local stabilisation, while isolated V<sub>Me</sub> defects (especially with S neighbours) are strongly destabilising. This explains the energy distribution peaks observed in the DFT‑derived data.

## Repository Structure

| File                         | Description                                                                                                                                                                           |
|------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `ccs_statistics.ipynb`       | Exploratory analysis of the CCS dataset: space‑group distributions, pairwise correlations, and heatmaps of defect counts.                                                             |
| `convex_hull_analysis.ipynb` | Construction and visualisation of the convex hull in the composition simplex, calculation of `E_above_hull`, and comparison between DFT and GNN predictions.                          |
| `holdout_test_1.ipynb`       | First holdout test (HT#1): evaluation of GNN models on DFT‑derived structures from the 5‑formula CCS subset.                                                                          |
| `holdout_test_2.ipynb`       | Second holdout test (HT#2): evaluation of models on a set of structures selected from the full CCS inference, including hull energy predictions and configurational entropy analysis. |
| `preliminary_test.ipynb`     | Preliminary evaluation of model performance on CCS structures with space groups below a symmetry threshold (P1, Cm, etc.).                                                            |
| `mx2che_tools.py`            | Utility functions for data processing, simplex coordinates, convex hull, entropy calculations, and structure manipulation.                                                            |
| `requirements.txt`           | List of Python dependencies.                                                                                                                                                          |
| `data/`                      | Datasets (see below for details).                                                                                                                                                     |

## Data Requirements

The notebooks expect the following data files to be present in a `data/` directory:

- `ccs_dataset_inference.pkl.gz` – main CCS inference data.
- `neat_elements_dataset.pkl.gz` – energies of pure elements (W, Mo, Se, S).
- `energies_df.pkl.gz` – convex‑hull reference energies.
- `2d-materials-point-defects-all-table.pkl.gz` – 2DMD dataset.
- `5formula_ccs_inference.pkl.gz` – inference for the 5‑formula CCS subset.
- `structures_Ndef.pkl.gz`, `structures_24def.pkl.gz` – DFT relaxation results.
- Additional inference files for HT#2 (e.g., `models-more_60k_highestSG_1-less_60k_all.pkl.gz`).

## Installation and Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/AIRI-Institute/MX2CHE.git
   cd MX2CHE
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
3. Use [2DMD_at_a_Glance](https://github.com/AIRI-Institute/2DMD_at_a_Glance) project to prepare `2d-materials-point-defects-all-table.pkl.gz` dataset and place it in the `data/` folder.
4. Launch Jupyter Lab or Notebook:
   ```bash
   jupyter lab
5. Run the notebooks in the following order (recommended):
- `ccs_statistics.ipynb`
- `convex_hull_analysis.ipynb`
- `preliminary_test.ipynb`
- `holdout_test_1.ipynb`
- `holdout_test_2.ipynb`

Each notebook contains detailed comments and can be executed independently after loading the data.
